# JPA conventions

## Entities
- Class name `<Name>`, table name `<plural>` via `@Table(name = ...)`.
- Mutable class with a no-arg constructor, getters and setters.
- Primary key is `UUID` with `@GeneratedValue(strategy = GenerationType.AUTO)`.
- Always declare `@Column` explicitly with `nullable` and `length`,
  because the schema is generated from the entity.
- Implement `Serializable`.

## Schema
Generated by Hibernate with `ddl-auto: update`. Use Flyway migration tool.
`validate` If a change would require schema changes, create a new migration.

## Repositories
`public interface BookRepository extends JpaRepository<BookModel, UUID> {}`
Derived queries for simple cases. No `@Query` unless the derived method
name would be unreadable.
